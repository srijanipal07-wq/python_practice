# 🐍 Python Practice Repository

Welcome to my **Python Practice Repository!** 🚀

This repository is a collection of my Python programming exercises, beginner-friendly programs, problem-solving solutions, and NPTEL practice codes. It reflects my learning journey and helps me strengthen my programming fundamentals.

## 📚 What's Inside?

- 🔢 **Number Programs** – Prime, Armstrong, Palindrome, Perfect Number, Fibonacci, and Factorial.
- ⭐ **Pattern Programs** – Star patterns and other pattern-based exercises.
- 🧮 **Mathematical Programs** – Combinations, maximum number, weighted mean, and more.
- 💻 **Basic Python Programs** – Hello World, type detection, swapping cases, and character frequency.
- 🎮 **Mini Projects** – Number Guessing Game, BMI Calculator, and Password Generator.
- 🎓 **NPTEL Practice** – Weekly Python programming exercises.

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/srijanipal07-wq/python_practice.git
   ```

2. Open the project folder:

   ```bash
   cd python_practice
   ```

3. Run any Python program:

   ```bash
   python filename.py
   ```

   Replace `filename.py` with the name of the program you want to run.
